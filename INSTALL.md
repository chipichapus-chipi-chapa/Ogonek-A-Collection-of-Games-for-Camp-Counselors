<h1 align="center">Как поставить «Огонёк» на телефон</h1>

<p align="center"><i>Поставить один раз — играть всю смену, даже без интернета.</i></p>

<p align="center"><b>Сайт приложения: <a href="https://chipichapus-chipi-chapa.github.io/Ogonek-A-Collection-of-Games-for-Camp-Counselors/">chipichapus-chipi-chapa.github.io/Ogonek-…</a></b></p>

Эту ссылку достаточно переслать вожатым: на сайте есть кнопки «Открыть приложение» и «Скачать для Android», а инструкция для своего телефона подсвечивается сама.

---

## <img src="docs/mascot/ogonek-love.png" width="40" align="absmiddle"> Android: приложение-файл (APK)

Самый «настоящий» вариант: Огонёк ставится как обычное приложение, все игры уже внутри, интернет не нужен даже при первом запуске.

1. Откройте [сайт](https://chipichapus-chipi-chapa.github.io/Ogonek-A-Collection-of-Games-for-Camp-Counselors/) и нажмите **«Скачать для Android»** (или сразу [по прямой ссылке](https://github.com/chipichapus-chipi-chapa/Ogonek-A-Collection-of-Games-for-Camp-Counselors/releases/download/android/ogonek.apk)) — загрузится `ogonek.apk`.
2. Откройте файл из уведомления или из «Загрузок».
3. Если телефон спросит — разрешите установку из браузера. Так Android реагирует на любое приложение не из магазина.
4. Нажмите **«Установить»**. На рабочем столе появится иконка **Огонёк**.

**Обновление:** скачайте `ogonek.apk` ещё раз и установите поверх — свои игры, фильтры и избранное сохранятся.

### Android: через браузер (без файла)

1. Откройте [сайт](https://chipichapus-chipi-chapa.github.io/Ogonek-A-Collection-of-Games-for-Camp-Counselors/) в **Chrome** и нажмите **«Открыть приложение»**.
2. Меню **⋮** → **«Установить приложение»** (или **«Добавить на главный экран»**).
3. Обновления приходят сами, когда телефон в интернете.

> Яндекс Браузер и Samsung Internet тоже подходят: ищите пункт «Добавить на главный экран» / «Установить».

## <img src="docs/mascot/ogonek-cool.png" width="40" align="absmiddle"> iPhone (Safari)

1. Откройте [сайт](https://chipichapus-chipi-chapa.github.io/Ogonek-A-Collection-of-Games-for-Camp-Counselors/) именно в **Safari** — в других браузерах на iPhone установка не работает.
2. Нажмите **«Открыть приложение»**.
3. Нажмите **«Поделиться»** (квадрат со стрелкой вверх внизу экрана) → **«На экран „Домой“»** → **«Добавить»**.
4. Откройте Огонька с иконки один раз при интернете — дальше он работает без сети.

### Проверьте, что всё работает без интернета

1. После установки откройте приложение с иконки и полистайте пару разделов.
2. Включите режим полёта.
3. Закройте приложение и откройте снова: все игры на месте.

### Как выходят обновления

Всё происходит само после отправки изменений в ветку `main` на GitHub:

- **Сайт** пересобирается и публикуется за 1–2 минуты (вкладка **Actions → «Сайт»**).
- **APK** собирается и заменяется в выпуске [«android»](https://github.com/chipichapus-chipi-chapa/Ogonek-A-Collection-of-Games-for-Camp-Counselors/releases/tag/android) (вкладка **Actions → «Android»**). Ссылка на скачивание при этом не меняется, а номер версии растёт сам.

### Ключ подписи Android — сделайте резервную копию!

APK подписывается ключом, без которого телефоны **не поставят обновление поверх** старой версии.

- Ключ и пароль лежат на компьютере в папке `~/ogonek-android-key/` (в репозиторий они не попадают).
- Копия для сборки — в секретах репозитория: **Settings → Secrets and variables → Actions** (`ANDROID_KEYSTORE_BASE64` и пароли).
- Сохраните папку `~/ogonek-android-key/` на флешку или в личное облако. Если ключ потеряется, придётся выпустить приложение заново, и вожатым нужно будет удалить старую версию.

### Быстрая проверка с компьютера (без публикации)

Телефон и компьютер — в одной Wi-Fi сети.

```bash
cd ~/mastro/ogonek
npm install
npm run phone:prod
```

Узнайте IP компьютера командой `hostname -I` и откройте на телефоне `http://<IP>:8090`. В этом режиме приложение не устанавливается и не работает без сети — это только для проверки.

## <img src="docs/mascot/ogonek-star.png" width="40" align="absmiddle"> Как пользоваться

<p align="center"><img src="docs/screens.png" alt="Экраны приложения" width="100%"></p>

- **Поехали!** на заставке → выберите возраст или «Общелагерные мероприятия».
- Возраст → **вид активности** (игры-минутки, спортивные, свечки…) → **игра**.
- **♡ В избранное** — игра появится во вкладке «Избранное».
- **＋ Создать** (красная кнопка внизу) — своя игра. Прямо в форме можно добавить **свой фильтр** (вид активности).
- **Мои** — «Моя копилка» с вкладками: свои **игры**, свои **фильтры** (здесь их тоже можно создавать и удалять) и резервная **копия**.
- **Поиск** — по названию и тексту, с фильтрами по возрасту и виду активности.
- Кнопка **«назад»** на телефоне возвращает на предыдущий экран.

### Важно про свои игры

Свои игры, фильтры и избранное хранятся **только на этом телефоне**. Чтобы не потерять их или передать другому вожатому:

- **«Мои» → вкладка «Копия» → «Сохранить в файл»** — скачается файл с вашими играми и фильтрами;
- на другом телефоне: **«Мои» → «Копия» → «Загрузить из файла»** и выберите этот файл (например, из Telegram или с Диска). Фильтры с одинаковым названием объединятся, дублей не будет.

Если удалить приложение или очистить данные браузера, свои игры пропадут. Сохраняйте файл время от времени.

## <img src="docs/mascot/ogonek-sleepy.png" width="40" align="absmiddle"> Частые вопросы

**Нет пункта «Установить приложение».**
Откройте ссылку именно в Chrome (на Android) или Safari (на iPhone), дождитесь полной загрузки и обновите страницу. Ссылка должна начинаться с `https://`.

**Открывается старая версия.**
Откройте приложение при интернете, закройте и откройте ещё раз: обновление подтягивается в фоне.

**Пропали мои игры.**
Скорее всего, очистили данные браузера или переустановили приложение. Восстановить их можно только из файла резервной копии («Мои» → «Копия» → «Загрузить из файла»).
