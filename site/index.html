Как поставить

Android

  1. Нажми «Скачать для Android» — загрузится файл ogonek.apk.
  2. Открой файл из уведомления или из «Загрузок».
  3. Если телефон спросит — разреши установку из браузера (это нормально для приложений не из магазина).
  4. Нажми «Установить». Иконка Огонька появится на рабочем столе.

Не хочется ставить файл? Нажми «Открыть приложение», затем в Chrome меню ⋮ → «Установить приложение».

Скачать APK

iPhone

  1. Открой эту страницу в Safari и нажми «Открыть приложение».
  2. Нажми «Поделиться» — квадрат со стрелкой внизу экрана.
  3. Выбери «На экран „Домой“» и нажми «Добавить».
  4. Открой Огонька с иконки один раз при интернете — дальше он работает без сети.

В других браузерах на iPhone установка не работает — только Safari.

Вопросы

Обновления придут сами?

Если ставили через браузер — да, при следующем открытии с интернетом. APK-версию обнови, скачав файл ещё раз и установив поверх: свои игры и избранное сохранятся.

Где хранятся мои игры?

Только на твоём телефоне. Чтобы не потерять их или передать другому вожатому: «Мои» → «Копия» → «Сохранить в файл».

Телефон пишет, что приложение небезопасно

Так Android предупреждает о любом файле не из магазина. Огонёк не спрашивает никаких разрешений и работает без интернета — все игры уже внутри приложения.
